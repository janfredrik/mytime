3. [P2] ink-subtle fails AA everywhere (25 uses), 10px badges, unnamed icon buttons <sm, popover lacks focus trap/return, invalid input visual-only. -> /impeccable audit then /impeccable harden
4. [P2] Destructive/empty actions lack guardrails: no undo, unconfirmed delete in LineEditor, submit/export on empty week. Fix: undo toast for deletes, gate submit/export on zero hours. -> /impeccable harden
